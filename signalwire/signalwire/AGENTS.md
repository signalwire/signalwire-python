# The signalwire package

This directory is the `signalwire` package of the SignalWire SDK for Python
(`signalwire-sdk` on PyPI).

To learn or use the SDK, run `sw-pydocs`. It maps the SDK, lists the docs,
examples and tutorials installed with it (under `_docs/` in an installed
package), and `sw-pydocs api <name>` shows signatures and docstrings from this
code. `llms.txt` in this directory lists the same docs.

To change the SDK itself, see the AGENTS.md at the root of its repository.
