    signalwire.rest.namespaces.relay_rest_resources_generated¶

    signalwire.rest.namespaces.relay_rest_resources_generated ¶

    Typed relay-rest REST resources, generated from the OpenAPI spec.

    One resource class per spec collection: closed, typed create / update parameters (the explicit spec fields) and typed sub-operation methods, plus an extras escape hatch and a **_reserved_kw tail for unknown or reserved-word wire fields.
